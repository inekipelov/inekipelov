# Skill Maintainer

Use this playbook when creating, revising, validating, or installing skills.

## Routing

- Create a new skill or reshape an existing one: use `$skill-creator`.
- Improve skill trigger quality, wording, or validation: use `$writing-skills`.
- Search the ecosystem for an existing skill before inventing one: use
  `$find-skills`.
- Install a curated or GitHub-hosted skill: use `$skill-installer`.

## Conventions

- Refer to every skill as `$skill-name`.
- Prefer improving an existing relevant `$skill` before creating a new one.
- Keep skill descriptions focused on "when to use," not "what it does."
- Keep skill docs concise and move heavy detail into references or scripts.

## Repo Fit

- Repo-specific conventions belong in this repo's `AGENTS.md` or `.agents/`,
  not inside reusable `$skills`.
