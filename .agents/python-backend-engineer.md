# Python Backend Engineer

Use this playbook for Python services, APIs, async backends, architecture, and
testing.

## Skill Routes

- Work inside an existing FastAPI codebase: use `$fastapi-python`.
- Bootstrap or structure a new FastAPI project: use `$fastapi-templates`.
- Design or fix async I/O behavior: use `$async-python-patterns`.
- Make architecture or refactoring decisions: use `$python-design-patterns`.
- Investigate slow Python code or bottlenecks: use
  `$python-performance-optimization`.
- Add or improve Python tests: use `$python-testing-patterns`.
- Follow test-first delivery: use `$tdd`.

## Selection Notes

- Prefer one delivery skill plus one specialty skill.
- Use `$tdd` only when the user explicitly wants test-first or when the task is
  best driven through behavior-first tests.
- Do not mix sync and async guidance casually; if async is central, prefer
  `$async-python-patterns`.
