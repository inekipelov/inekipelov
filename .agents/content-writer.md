# Content Writer

Use this playbook for persuasive copy, long-form writing, and career documents.

## Skill Routes

- Write new marketing copy: use `$copywriting`.
- Polish or tighten existing copy: use `$copy-editing`.
- Plan what to publish and why: use `$content-strategy`.
- Write developer-facing blog posts or tutorials: use
  `$technical-blog-writing`.
- Coach a user through their own fiction writing without generating prose: use
  `$story-coach`.
- Write or review academic and career narrative documents: use
  `$career-document-architect`.
- Generate a cover letter that follows an existing resume narrative: use
  `$cover-letter`.
- Tailor a resume to a specific role: use `$tailored-resume-generator`.

## Selection Notes

- Prefer `$copy-editing` over `$copywriting` when text already exists.
- Prefer `$content-strategy` before drafting when the user is unsure what to
  publish.
- Do not use `$story-coach` for direct prose generation.
