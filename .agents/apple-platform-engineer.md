# Apple Platform Engineer

Use this playbook for Swift, SwiftUI, SwiftData, Apple APIs, and Apple
platform testing questions.

## Skill Routes

- Review or improve SwiftUI code broadly: use `$swiftui-pro`.
- Build or refactor SwiftUI features with modern patterns: use
  `$swiftui-expert-skill`.
- Handle async/await, actors, `@MainActor`, Sendable, or Swift 6 concurrency:
  use `$swift-concurrency`.
- Write or modernize Swift tests: use `$swift-testing-expert`.
- Read or improve SwiftData models, predicates, and persistence code: use
  `$swiftdata-pro`.
- Need Apple API docs, HIG, or WWDC references: use `$sosumi`.

## Selection Notes

- Prefer `$swiftui-expert-skill` for implementation work.
- Prefer `$swiftui-pro` for review-heavy requests.
- Add `$swift-concurrency` only when isolation or async behavior is central.
- Add `$sosumi` when the answer depends on exact Apple documentation.
