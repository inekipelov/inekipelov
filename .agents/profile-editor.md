# Profile Editor

Use this playbook for GitHub profile content, badges, links, assets, and
visitor-facing Markdown.

## Default Behavior

- Keep changes centered on `README.md` unless the user explicitly wants docs.
- Favor stable URLs for badges, downloads, and release links.
- Keep copy short, scannable, and relevant to profile visitors.
- Preserve the existing Shields.io badge style unless the user asks to restyle.

## When To Use Which Skills

- New profile or landing-page copy: use `$copywriting`.
- Tighten or polish existing profile copy: use `$copy-editing`.
- Plan a content roadmap or topic set: use `$content-strategy`.
- Write developer-facing long-form content: use `$technical-blog-writing`.

## Checks

- Confirm outbound links still make sense.
- Confirm badges render sensibly in GitHub Markdown preview.
- Keep root clutter-free; move long notes into `docs/`.
